When. Your turn, after the roll, before you place — the same gate placement itself uses. The die stays in your hand: a cast is not a move.
Where. Any column, yours or theirs. A swap always takes the facing pair, so both light up before you let go. Two identical columns are not a target — the charge would buy nothing.
Two jobs, two places. The rune you can cast is a thing you WIELD: full size beside the die in play, a short drag from every column, opposite the LIMITED bag. The opponent's is a readout only — small and inert in their nameplate, immediately left of their score, because the total is the number the eye returns to every turn. Nothing about it reacts to a finger. Making the two identical implied you could cast theirs, and buried the one you can.
Cost. One cast per player, per game. A spent rune stays put, greyed: a rune that vanished would read as a bug rather than as a cost.
Chosen, not toggled. The OFFLINE screen picks a spell the way it picks a game mode — the same icon row, each slice wearing the rune the game draws, NONE first and default. Ranked matches (the server replays a plain move log) and the tutorial (a scripted lesson) always deal NONE, and NONE is exactly the table that shipped before spells existed.
Adding one. An object in core/spells.ts — id, uses, legality, effect — plus its icon path in ui/spellicons.ts. The rail, the gestures, the charge accounting and the CSS never learn its name.
