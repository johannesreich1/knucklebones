Where it stands. On the first board column, exactly as the rune card stands on the third — the same expression with the sign flipped, so the two things flanking the die are symmetric about it and each lines up with a real column above and below. In landscape the lane is only as wide as the die, so the pair stacks instead: rune above, bag below, on the same 7px gap.
What it says: this much is left — as a length, which is the one quantity a person reads without counting or fixating. The pile is unchanged: the same shells, the same fan, the same anonymity. It rounds to a quarter and always has, which is why the last six draws all look alike to it; the column beside it does not round, and between 6 and 1 it is the only thing still moving.
The draw comes off the top. Every draw, not only the one in six that costs the pile a layer. A fifth shell (.take, ui/bag.ts) rides whatever layer is currently on top and is the only thing that moves, so the four below restack underneath it instead of fighting an animation for the same element. It is armed only when the count falls by exactly one — a reconnect that jumps, a fresh game, or FA4 rewinding its own bag repaints with nothing coming off anything.
Achromatic. No hue, so colour blind mode and the seven pickable player hues cannot touch the gauge; reduced motion keeps the identical picture and loses only the 300ms lift. The claim that had to be dropped: this was proposed as a U-shaped collar of 24 countable teeth, and the adversarial pass killed it for anchoring the scale exactly where the shells permanently sit — the floor and right wall are never visible, and the lit run burned toward the pile, hiding the final teeth under the thing they measure. Only the left gutter survives at every depth, and 24 marks in 36px is a 1.5px pitch nobody can count at arm's length. So the counting read is gone: this is a bar, not a scale. Whether a 2px bar survives a low-DPR phone is a measurement, not an opinion.
