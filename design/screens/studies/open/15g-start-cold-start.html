A7 · COLD START

Everything comes up bone — the die grey, the wordmark unlit — and the colour arrives on one curve across both at once. The neon is not what the app is made of; it is what the app switches on.

It teaches the interface's rule in one beat. This app is bone with light put on it: grey dice that take a plate, grey type that takes a gradient, a CTA that takes a glint. Showing that happen once at boot means a player has already seen the grammar before they read a word — and every lit thing they meet afterwards is the same idea repeating. Refusing a sequence is the design decision. A1 lights the seam first and lets colour spread from it, which puts the mark ahead of the type and makes the seam the hero. Here there is no first thing: mark and wordmark share one window and one curve. That is either a cleaner claim or a duller one, and it is the axis these two cards exist to test against each other. How the type warms. The h1's lit state is the app's own shared gradient, faded up over a bone fallback with a ::after that repeats the glyphs — same font, same metrics, no restated type CSS. The mark can only use a filter, because the token is an image and saturate() is the only lever an image gives you. The frame that must never render. An unlit grey die with a coloured halo already around it looks broken, so the glow and the colour are on the same keyframes, arriving together. Split them for "polish" and the first thing a new player sees is a bug. Cheapest in the family, and it shows. No transform, no travel, no second copy of the mark — one filter and one opacity. It is also the least memorable: nobody describes a colour fade to a friend.
