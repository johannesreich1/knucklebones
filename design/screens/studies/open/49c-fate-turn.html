What it says: same hand, different die. It is the smallest possible statement of the rule, and smallness is a real virtue for a rune that can be cast twice in a match on top of an already-animated roll — nothing is cleared, nothing travels, the eye never has to re-find the die in play.
It survives everywhere. No lane, no second element outside the die's own box, no interaction with the bag or the rune rail, and it costs one transform on one element.
Cost: a turned-over die says the two faces were always the same object — which is exactly what FATE does NOT do. The rule is that the first die goes back to the supply and a different one is drawn; a coin-flip reads as "the same die showing something else", which is a re-roll, and a re-roll is the one thing this rune must not be confused with. Under LIMITED that confusion has teeth: if it looks like the same die, the bag falling by one looks like a bug.
